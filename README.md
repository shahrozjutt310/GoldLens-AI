# GoldLens AI

GoldLens AI is a Kotlin + Jetpack Compose Android application for gold market analysis and demo trading intelligence.

Overview
- Dark trading interface for XAUUSD monitoring
- Home, chart, AI assistant, market news, and settings screens
- Explicit market-connection status instead of fake live prices
- Urdu and Roman Urdu experience for the AI assistant
- Empty, loading, and error-state handling
- Settings for language, theme, voice output, and timeframe

Important notes
- This app intentionally does not connect to real market-data or AI services by default.
- If no provider is configured, the UI shows `MARKET DATA UNAVAILABLE` and keeps all values clearly marked as demo information.
- No private API keys or credentials are stored in source code.
- No trades are executed.

Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK Platform 34
- Android SDK Build Tools 34
- Gradle 8.7+ or wrapper generated by Android Studio

Local setup
1. Install Android Studio.
2. Install Android SDK Platform 34 and Build Tools 34.
3. Open the project in Android Studio.
4. Accept the Gradle sync when prompted.
5. Create `local.properties` in the project root if needed:

   sdk.dir=/path/to/Android/Sdk

6. Build a debug APK:

   ./gradlew assembleDebug

   On Windows:

   gradlew.bat assembleDebug

Build output
- Debug APK: app/build/outputs/apk/debug/app-debug.apk
- Release APK: app/build/outputs/apk/release/app-release-unsigned.apk

If you want live services
- Provide secure API keys in `local.properties` or environment variables.
- Configure provider endpoints in a dedicated settings or secret management layer.
- Keep keys out of source control.

Repository structure
- `app/src/main/java/com/goldlensai/MainActivity.kt` — app entry point
- `app/src/main/java/com/goldlensai/data/MarketData.kt` — demo market data
- `app/src/main/java/com/goldlensai/ui/theme` — color and typography configuration
- `app/src/main/res` — Android resources

Android build status in this environment
- The repository is prepared for Android development, but this environment does not include a validated Android SDK/JDK toolchain, so no real APK was generated here.
- To build on your machine, use the commands above after installing the Android SDK and JDK 17.
